راهنمای راه اندازی ربات تلگرام دانلودر هوشمند شبکه های اجتماعی
مرجع انتشار: وب سایت سورس یو (sourcio.ir)
کانال تلگرام: @SourcioIR
پشتیبانی: @SourcioSupportBot
====================================================================

این سورس کد به صورت کاملا رایگان و متن باز توسط وب سایت سورس یو
ارائه شده است. با استفاده از این ربات، کاربران می توانند انواع مدیا
(ویدیو، ریلز، استوری، پست، شورتز و گیف) را از اینستاگرام، یوتیوب،
تیک تاک، پینترست، توییتر (ایکس)، تردز و ردیت دانلود نمایند.

--------------------------------------------------------------------
۱. پیش نیازهای لازم
--------------------------------------------------------------------
- سرور مجازی یا هاست پایتون (لینوکس ابونتو / دبیان)
- پایتون نسخه 3.10 یا بالاتر
- ابزار FFmpeg برای استخراج و فشرده سازی ویدیوها

دستور نصب پایتون و ffmpeg روی ابونتو:
sudo apt update && sudo apt install -y python3 python3-venv python3-pip ffmpeg

--------------------------------------------------------------------
۲. مراحل راه اندازی در ۳ دقیقه
--------------------------------------------------------------------
۱) ایجاد محیط مجازی پایتون و نصب وابستگی ها:
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt

۲) تنظیم فایل پیکربندی (.env):
   فایل .env.example را به .env تغییر نام دهید یا کپی کنید:
   cp .env.example .env

   سپس فایل .env را ویرایش نمایید:
   - توکن ربات دریافتی از BotFather را در BOT_TOKEN وارد کنید.
   - آیدی عددی تلگرام خود را در ADMIN_IDS قرار دهید.
   - سهمیه دانلود روزانه کاربران (USER_LIMIT_ENABLED) را تنظیم فرمایید.

۳) تست سلامت سیستم و دیتابیس:
   python -m src.media_bot.cli doctor

۴) اجرای ربات:
   python -m src.media_bot.cli all

--------------------------------------------------------------------
۳. اجرای دائمی به عنوان سرویس پس زمینه (Systemd Service)
--------------------------------------------------------------------
فایل های نمونه سرویس systemd در پوشه deploy/systemd قرار دارند.
می توانید سرویس simple-media-all.service را به /etc/systemd/system/
منتقل کرده و با دستورات زیر فعال کنید:
sudo systemctl daemon-reload
sudo systemctl enable simple-media-all
sudo systemctl start simple-media-all

--------------------------------------------------------------------
۴. سورس های تجاری و پرچمدار سورس یو
--------------------------------------------------------------------
در صورت نیاز به سورس های پردرآمد و پیشرفته با لایسنس معتبر و هاست رایگان:
- سورس ربات آپلودر پیشرفته
- سورس ربات پیام ناشناس
- سورس ربات چت ناشناس و دوستیابی
- سورس ربات هوش مصنوعی ChatGPT
به آدرس sourcio.ir مراجعه فرمایید یا از کد تخفیف SOURCIO30 استفاده کنید.
