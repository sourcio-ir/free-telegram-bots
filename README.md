## پیش نیازهای راه اندازی

برای راه اندازی این سورس ها نیاز به یک هاست لینوکس با مشخصات زیر دارید:
* نسخه PHP 8.1 یا بالاتر
* فعال بودن ماژول های `curl` و `mbstring` و `json`
* گواهی SSL معتبر (HTTPS) جهت فعال سازی وب هوک تلگرام
* توکن ربات از طریق BotFather@ در تلگرام

> برای انتخاب هاست مناسب بدون مسدودی، می توانید مقاله **[راهنمای انتخاب بهترین هاست برای ربات تلگرام](https://sourcio.ir/best-hosting-for-telegram-bot/)** را مطالعه فرمایید.

## آموزش سریع نصب و ست وب هوک

۱. ابتدا فایل های سورس مورد نظر را در مسیر `public_html` هاست خود آپلود نمایید.
۲. فایل تنظیمات (`config.php`) را باز کرده و توکن ربات دریافتی از BotFather و آیدی ادمین را وارد کنید.
۳. دستور ست کردن وب هوک را در مرورگر خود با فرمت زیر اجرا کنید:

```text
https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=https://your-domain.com/path-to-bot/bot.php
```

۴. پس از دریافت پاسخ `{"ok":true,"result":true,"description":"Webhook was set"}`، ربات شما آماده فعالیت در تلگرام است.
